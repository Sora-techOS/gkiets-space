# gkiet's space

My very first desktop app — a simple, personal study planner and Pomodoro timer built to keep me focused while listening to Spotify.

![Platform](https://shields.io)
![Built With](https://shields.io)

## About this project
This is my first time building and packaging a desktop application (`.exe`). I wanted a clean, distraction-free space on my PC to track my study schedule, run Pomodoro sessions, and see what's currently playing on Spotify without opening a browser.

## What it does
- **Study Calendar:** Simple Week, Day, and Month views to plan classes and study sessions.
- **Task List & Workload:** Keep track of daily to-dos and see how heavy my study load is.
- **Pomodoro Timer:** Built-in 25/5/15 focus timer (with a fullscreen focus mode).
- **Spotify Widget:** Automatically detects what's playing on the Windows Spotify app with basic playback controls.
- **System Tray & Auto-start:** Minimizes quietly to the Windows system tray and launches on startup.

## Running it locally
If you want to run or tweak the code yourself:

```bash
# Clone the repo
git clone https://github.com
cd gkiets-space

# Install dependencies
npm install

# Run the app
npm start

# Build Windows .exe
npm run build
```
